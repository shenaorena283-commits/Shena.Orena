Sleep Log App
Sleep Log is an application created by Shena S. Oreña, a BS Information Technology student from BSINTE-2A, using FlutterFlow.io. This app helps users track their sleeping and waking times. It can record bedtime and wake-up time, automatically calculate the total hours of sleep, and show sleep history, average sleep duration, and weekly statistics. To use the app, simply open the provided link, and the app will automatically show its main interface. There is also an Install option on the side that allows users to install the app on their devices for easier access. The main purpose of this app is to help users monitor their sleeping habits and keep track of their daily sleep schedule.
